# harshavardhan-dev.vercel.app

Personal site of Harsha Vardhan, AI Engineer (agentic AI, voice AI agents, production LLM systems).

- Next.js 15 (App Router) · TypeScript · Tailwind CSS 4 · GSAP + ScrollTrigger · Lenis smooth scroll
- All copy lives in `lib/content.ts`; the hero's call-to-record animation is `components/CallToRecord.tsx`
- `public/Harsha_Vardhan_Resume.pdf` is the public resume (no phone number)

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
```
